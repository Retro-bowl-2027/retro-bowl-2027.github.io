Cell Machine – Build a tiny machine and press play

Push, rotate, generate. The cells in Sam Hogan's 2020 puzzle each do one simple job, and the levels ask you to combine those jobs into a working machine. You place the pieces you are given, start the simulation and watch the chain reaction. If the target ends up where it should, the level is solved.

The basics of Cell Machine

Each level gives you a set of cells and a space to place them. Movers push forward, rotators turn their neighbors, generators copy what sits behind them, and other types add rules of their own. Once your layout is ready, press play and the cells act on each other step by step. Success depends on the order of interactions, so small placement changes can flip the result.

Getting started

  • Read what each available cell does before placing anything.
  • Place a single mover and run the simulation to see the timing.
  • Add one cell at a time and run the machine after each change.
  • Reset and rearrange when the chain reaction goes wrong.

Tips from experience

Think in steps. The simulation runs in discrete ticks, so trace each cell's action one tick at a time. Generators can multiply a problem as fast as a solution, so place them carefully. When a level fails, watch for the moment things go wrong and work out which cell caused it. Good machines usually use fewer pieces than you expect.

Who should play it

Made for logic fans and anyone who enjoys programming-style puzzles. The rules are consistent and learnable. It has a plain look and no story, which may put off players who want more than pure puzzling.
